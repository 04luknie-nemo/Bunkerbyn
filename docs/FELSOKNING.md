# Felsökningslogg

Här skrivs fel ner som tog mer än 15 minuter att lösa. Syftet är att träna felsökning som disciplin: att följa tråden från symptom till rotorsak i stället för att gissa.

Stegen följer kursen Problemlösning: [Att angripa ett oklart problem](https://mardby.se/w/index.php?title=Att_angripa_ett_oklart_problem). Det är ett sätt att tänka, inte en checklista. Hoppa fram och tillbaka mellan stegen när det behövs.

## Mall

```
## F<nummer>: <kort rubrik>

Datum: ÅÅÅÅ-MM-DD
Issue eller pull request: #<nummer>

**Symptom:** Vad syntes, och var?

**Förstå:** Vad borde ha hänt? Vad vet jag, och vad antar jag bara?

**Bryt ner:** Vilka delar kan felet ligga i?

**Hypoteser och prov:**
1. <hypotes>: hur jag prövade den och vad det visade
2. <hypotes>: hur jag prövade den och vad det visade

**Rotorsak:** Var felet faktiskt uppstod, och varför det syntes någon annanstans.

**Åtgärd:** Vad som ändrades.

**Lärdom:** Vad jag gör annorlunda nästa gång, eller vilket verktyg som hade hittat felet snabbare.
```

## Loggen

Första posten blir kameran som bara rörde sig lite med WASD. Skriv den själv med mallen ovan.
